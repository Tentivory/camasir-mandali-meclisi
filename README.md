# Çamaşır Mandalı Meclisi

> Balkonda asılı duran her mandal, aslında bir milletvekilidir.  
> Bu iddia bilimsel değildir. Yine de çalışır.

## Resmî Açıklama (Aşırı Ciddi)

Bu depo, Türkiye Cumhuriyeti balkonlarında fiilen mevcut olan ama henüz Resmî Gazete'de yayımlanmamış **Çamaşır Mandalı Meclisi**'nin sayısal ikizidir.

Yazılım:

1. Rastgele mandal milletvekili üretir.
2. Onlara parti verir (kuruçama, ıslak çorap, rüzgâr vs.).
3. Nutuk attırır.
4. Çamaşırın kaderini oylar.

Hiçbir çamaşır bu süreçte gerçekten kurumaz. Bu bir özelliktir, hata değil.

## Kurulum

```bash
python3 meclis.py
```

Başka bir şey kurmanıza gerek yok. Meclis zaten balkonda kurulu.

## Anayasa (Taslak)

- Madde 1: Egemenlik kayıtsız şartsız mandallara aittir.
- Madde 2: Tek çorap kaybolursa araştırma komisyonu kurulur.
- Madde 3: Rüzgâr veto yetkisini kötüye kullanamaz; kullanırsa çamaşır düşer.
- Madde 4: Bu maddeler çamaşır ipine asılıdır, indirilemez.
